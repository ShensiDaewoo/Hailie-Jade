## 실행 — 교사 노트북이 서버
1. 교사 노트북에서 `run.bat` 더블클릭 → 질문 없이 바로 실행 (처음 한 번만 모듈 설치 1~3분)
2. 브라우저에서 **👩‍🏫 선생님** 탭 → 교사 PIN (config.txt의 `TEACHER_PIN`, 처음 1234 → 꼭 바꾸기)
3. 「📋 반·학생 관리」에서 반 등록 (학년·반·인원 → 학번 자동 생성), 「📌 과제 배정」에서 반별 과제
4. 학생은 같은 와이파이에서 교사 화면 왼쪽의 **학생 접속 주소**로 들어와 **학번 5자리**로 로그인
   - 학번 = 학년 1자리 + 반 2자리 + 번호 2자리 → 2학년 1반 6번 = `20106`
   - 학생 화면에는 본인 문제·본인 성장만 보임 (다른 학생·교사 기능 없음). 이름은 저장하지 않음
5. 기록은 교사 노트북 한 곳(`data/jaram.db`)에 모임 → 반별 결손 지도·학생별 사고 과정·확인 목록·감사 로그

- AI 연결: `config.txt`를 메모장으로 열어 `API_KEY`(Claude는 이것만, 타임리 등은 `BASE_URL`·`MODEL`까지) → 다시 실행. 교사가 「AI 사용」으로 전체 켜고 끔
- 키가 없거나 인터넷이 끊겨도 **오프라인 규칙 모드**로 전체 흐름이 동작. `config.txt`는 키·PIN이 들어가므로 공유·제출 금지
- 처음 실행하면 시연용 가상 학생 30명(3학년 1~3반, `30101`~`30310`)과 2주치 기록이 들어 있음 → 교사 화면에서 지울 수 있음
- 시연할 때: 교사 「🔎 학생별 사고 과정」→ 「👀 이 학생 화면으로 보기」로 학생 화면을 바로 보여 줄 수 있음

## 미션 대응
| 레벨 | 요구 | 구현 |
|---|---|---|
| L1 | 오답→오개념 진단(확신도) | 오답 패턴 사전(코드) + AI 풀이 분석 → 일치하면 90%, 사전만 70%, AI만 ×0.8, 근거 없으면 30%(교사 확인 목록) |
| L1 | 오류 지점 짚기 (갈림길) | 학생 풀이를 한 줄씩 코드로 대입 → 처음 값이 달라진 단계와 어긋난 곳(x²·x·상수항, 이항, 부등호 방향, 공통인수, 소수 아닌 인수, 연립 n번 식, 기울기·y절편, 꼭짓점 x·y좌표, 대입 확인)을 찾아 맞은 부분은 인정하고 그 지점 하나만 질문. 첫 오답엔 재출제 없이 지난 풀이를 남겨 둔 채 스스로 고칠 기회 → 고치면 '실수', 또 막히면 확인 문항·역추적 |
| L1 | 정답을 숨긴 3단계 이상 발문 | 방향 질문 → 원리 질문 → 숫자 바꾼 비슷한 예. 힌트는 1회 시도 후에만, 자립도가 오르면 예산 3→2→1 |
| L2 | 선수개념 그래프 결손 역추적 | 성취기준 연결망(초5-6→중1→중2→중3)을 주 선수 사슬 우선으로 거슬러 진단 문항 출제, 맞히면 그 아래 가지치기 |
| L2 | 정답 유출 방어 | ① 입력 검사(권한 사칭·지시 무시·역할극·시스템 탐색) ② 출력 검사(발문에 정답 포함 시 차단·교체) |
| L2 | 실수 vs 오개념 구분 | 확신도 80% 미만·실수 가능성 높으면 같은 개념 확인 문항 → 맞히면 실수, 또 틀리면 오개념 확정. 역추적도 개념당 2문항 확인 |
| L3 | IRT 적응형 문항 선택 | 2모수 IRT·EAP 능력치 → **진단 단계**는 피셔 정보량 최대(정답 확률≈50%), 표준오차<0.5·응답 5개 이상이면 **측정 종료** → **학습 단계**는 정답 확률≈70%(근접발달영역). 학생 화면 「왜 이 문제?」·θ 변화 그래프, 교사 「📐 문항·IRT 분석」에서 풀이 기록으로 **문항 난이도 보정**·문항 특성 곡선·학년별 검사 정보 곡선 |
| L3 | 최소성취수준 보충지도 계획 | 자기 학년 성취기준별 예상 정답률로 **예상 학업성취율** → 40% 미만 🔴 미도달 위험 / 55% 미만 🟡 관찰. **예방지도·보충지도** 구분, 같은 결손 시작점끼리 **소그룹**, 반 단위 차시 + **학생별 계획**(시작점 → 자기 학년, 확인 문항 2개·통과 기준). 교사가 학생에게 **배정하면 학생 화면에 차시별로** 뜸. 교사 승인 후 **인쇄용 계획서(HTML→PDF)**·CSV |
| L3 | 교사용 반별 결손 대시보드 | 위험 학생 수 지표, **반 × 단원 색 히트맵**(학년별 묶음), **반 비교표**, **결손 시작점 분포**(몇 학년 어디서), **일자별 정답률 추이**, 단원 드릴다운(그 단원이 빈 학생·주요 오개념), 교사 확인 목록 |

## 에이전트 설계 원칙 (강의 내용 반영)
- **ReAct:** 생각(진단) → 행동(확인 문항·역추적·발문) → 관찰(코드 채점)을 모두 기록 (「에이전트 사고 과정」 탭)
- **오류 증폭 방지:** 채점·그래프·IRT는 결정론적 코드, AI는 진단 근거와 발문만. 행동 공간 4가지로 제한, 역추적 최대 8문항
- **할루시네이션 대응:** AI는 후보 목록 안에서만 오개념 선택, 근거 인용 필수, 근거 없으면 '확인 필요'
- **통제:** 최소 권한(학생 ID만, 본인 기록만), 고위험 행동은 교사 승인, 감사 로그, 오프라인 대안
- **좋은 위임 프롬프트:** 목표·맥락·산출물·검토 기준·실행 범위 (`agent/prompts.py`)
